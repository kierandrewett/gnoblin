Install Gnoblin ​

Gnoblin manages your windows. A separate desktop shell provides the bar, dock and launcher. Install both before your first login.

Choose your system ​

SystemInstall method
FedoraInstall from COPR
NixOSAdd the NixOS module
Arch / CachyOSBuild from source
Debian / UbuntuInstall the official package
openSUSEBuild from source

Gnoblin installs alongside GNOME. Your existing GNOME session remains available.

After installing ​

  1. Install a desktop shell.
  2. Log out. At the login screen, choose your user, open the session selector, and choose Gnoblin.
  3. Log in and configure Gnoblin.

If there is no bar or launcher, right-click the desktop and choose Open Terminal. See first-login troubleshooting.

For development builds, see source installation. Release maintainers should use the packaging guide.
