Gnoblin manages windows, workspaces, input and desktop services. Your chosen shell supplies the visible desktop; a regular GNOME login remains available.

Make it yours ​

  • Shortcuts — launch commands and change keys.
  • Window rules — choose which windows a setting affects.
  • Effects — blur, corners, borders and shadows.
  • Titlebars — client and server decorations.
  • Animations — timing and motion.
  • All settings — find an option.
