# Services role: provider status

This page records what each provider of the services role does today. Each row
cites the code or test it rests on. Real-process evidence comes only from the
run records in `design/e2e-*.md`. A row marked "needs a real session" has unit
or integration tests on a private bus, but no real-process run.

Status values:

- **done**: code and tests exist, and a real-process run exists where stated.
- **partial**: code and tests exist, but part of the behaviour is missing or
  unproven.
- **absent**: no code in the Rust workspace.
- **needs a real session**: tests pass on a private bus; the real service has
  not been exercised.

## Supervision

The services role is one child of the guardian (`crates/gnoblin-session`).

- Restart: `Restart::Backoff(Backoff::guardian())` (`crates/gnoblin-session/src/plan.rs:157`).
- Readiness: it must report ready within `DEFAULT_READY_WITHIN` (`plan.rs:13`). It reports ready once
  `Agents::start` returns (`crates/gnoblin-services/src/role.rs:171`).
- Missing bus: a provider whose bus is missing is skipped, and the role carries on.
- Missing provider: a slot with no provider fails closed and names the slot.
  `crates/gnoblin-service-core/tests/failure_modes.rs`: `no_provider_fails_closed_and_names_the_slot`.

Real-process evidence: `design/e2e-smoke.md` "Services stall (fixed)" records a
run where the services role reached `session ready`. `design/e2e-keyring.md`
records the keyring scenarios on a real session.

## Gaps that need a real session or hardware

- polkit: a real polkitd and a real prompt, with the agent answering.
- GeoClue: the agent exists and is tested on a private bus (see the row above).
  Not run against a real GeoClue service or a location request. Next slice: a
  real GeoClue run on hardware, no code change.
- PipeWire privacy: not ported. The monitor is only in the C tree
  (`src/agents/gnoblin-pipewire-monitor.c`). Next slice: port the monitor to a
  Rust crate in the services role, tested against a fake PipeWire node on a
  private bus; a real PipeWire daemon is needed for the final check.
- `org.gnome.ScreenSaver`: tested on a private bus only. No run beside a real GNOME
  session that owns the name, so the refusal path has not met a real owner. Next slice:
  a real GNOME client run on hardware, no code change.
- logind unlock: deliberately absent. Unlock stays with the locker's password.
  Next slice: none unless a decision changes; a logind `Unlock` must not bypass
  the locker.
- logind: a real seat, a real `systemctl suspend`, and `loginctl lock-session`.
- SessionIdle and ScreenSaver: a real session bus client, such as a video
  player, holding `Inhibit`.
