## 3. Recommended architecture

1. **Separate process `gnoblin-js`** (spec §18: restartable privileged client). Compositor ↔ JS over a Unix socket with versioned, coalescing messages (transactions, input events, property revisions). The compositor never calls JS on the render/event thread; it renders from the last committed scene policy if the JS peer is late, dead, or reloading.
2. **Threads in `gnoblin-js`**: (a) _JS thread_ owns every `Runtime`/`Context` (never `parallel`), runs a single-threaded loop: IPC messages, timers, job pump; (b) _watcher thread_ (notify) → channel; (c) _watchdog thread_ (or the supervisor in the compositor) watching a heartbeat + the budget atomics. Only plain `Send` data (serialized messages, `Arc<Budget>`) crosses threads.
3. **Engine crate boundary**: one crate `gnoblin-js-engine` is the only user of rquickjs (generation, loader, TS strip, host-object bridge). Do not build an engine-abstraction trait [I]; a swap would rewrite that crate.
4. **Cargo features**: `rquickjs = { version="0.14", default-features=false, features=["std","loader","classes","properties","macro","phf"] }`; **no** `dyn-load` (spec §3: no `.so` from JS; extensions go through the extension host, §17), **no** `allocator`/`rust-alloc` (would turn `set_memory_limit` into a no-op [V]), **no** `parallel`, **no** `futures` initially (own timer/job loop; fewer lifetime traps) [I]. Verify which of `classes/properties/macro` the derives actually need [U].
5. **Context**: `Context::builder().with::<(Date,RegExp,RegExpCompiler,Json,Proxy,MapSet,TypedArrays,Promise,WeakRef)>()`. Omit `Eval` (no `eval`/`new Function` for user code) and `Performance`; the REPL uses host `Ctx::eval*` [I: C-level `JS_Eval` does not need the script-visible `eval` global; confirm]. No `console` etc. except what the bridge installs.
6. **Process hardening** (defence in depth, QuickJS is C): Landlock (read `~/.config/gnoblin`, `/usr/share/gnoblin`, runtime dir socket), seccomp allow-list, no network namespace by default, cgroup `MemoryMax`/`RLIMIT_AS` above the QuickJS limit, and a hard watchdog SIGKILL.
7. **Stock library** (`gnoblin`, `gnoblin/*`, layouts, bindings) is precompiled to bytecode and embedded (`loader::bundle`/`embed!`, `phf` feature [V README]); a dev env var may point at a source tree and watch it.

## 4. (a) "Invisible" observable fields on user subclasses without user-written Proxy

Requirements (§16, §1 rule 14): `class Spiral extends Layout { constructor(){super(); this.radius=900} }`, also `radius = 900` class fields, no decorators/schemas; preserve identity, reflection, method dispatch, private fields "as far as supported".

**Recommended (A): base-class constructor returns an internal Proxy that traps only `defineProperty` and `deleteProperty`.**

```js
// stock lib, gnoblin/observable.js (library code, never user code)
const kId = Symbol("gnoblin.id");
export class Observable {
    // Layout, Binding, ... extend this
    constructor() {
        const id = native.newObservable(new.target); // Rust-side record, no reference to `this`
        return new Proxy(this, {
            defineProperty(t, k, d) {
                if (typeof k === "string") native.touch(id, k, d);
                return Reflect.defineProperty(t, k, d);
            },
            deleteProperty(t, k) {
                if (typeof k === "string") native.touch(id, k);
                return Reflect.deleteProperty(t, k);
            },
        });
    }
}
```

Why only `defineProperty`: with **no** `set` trap, `p.x = v` runs OrdinarySet with `Receiver = proxy`, which ends in `Receiver.[[DefineOwnProperty]]` → trap; class-field initialisers (`radius = 900`) use `[[DefineOwnProperty]]` too → same trap. One trap covers both write paths, prototype setters still see `this === proxy`, and there is no double-trap from `Reflect.set(t,k,v,receiver)`. [I from ES spec; QuickJS is test262-conformant but confirm with a spike.]

Semantics and costs:

| Aspect                                     | Result                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Identity                                   | The derived constructor's `this` is the value returned by `super()` = the proxy. Every method, arrow function and `workspace.layout = x` sees the same proxy; `===`/`instanceof`/`Object.getPrototypeOf` behave (no `getPrototypeOf` trap; falls through to target). Target must never escape the base constructor (no closures/registries capturing `this` there). Key all registries by the proxy (what user code holds), via `kId` stored through the proxy or a `WeakMap`. |
| Private fields `#x` in **user** subclasses | Work and are unobserved by design: `DefinePrivateField` writes directly into the proxy object's shape, no trap (`quickjs.c:9284-9346` [V]); brand checks on the proxy succeed.                                                                                                                                                                                                                                                                                                 |
| `#x` in the **library base class**         | **Forbidden**: base-class private fields are installed on the raw target before `return proxy`; later methods called on the proxy throw TypeError. Use symbols/WeakMap in observable bases (lint it).                                                                                                                                                                                                                                                                          |
| Native-backed base                         | A Rust `JsClass` instance cannot be the observable base (`Class::from_object` fails on a Proxy). Keep `Layout` a JS class holding a native handle (`this[kId]`) and forward to Rust by id.                                                                                                                                                                                                                                                                                     |
| Write cost                                 | one JS trap call + `Reflect.defineProperty` + a native call, ~µs scale [I]; fine for config/state writes, measure for per-frame writers. Coalesce `touch` into a per-transaction dirty set in Rust.                                                                                                                                                                                                                                                                            |
| Read cost                                  | no `get` trap, but QuickJS proxy `[[Get]]` still looks up the handler `get` property then forwards: maybe 2-5× a plain read [I]. `compute()` reads a few fields per child; acceptable, but benchmark layout compute at N=200 children.                                                                                                                                                                                                                                         |
| Reflection                                 | `Object.keys`, `JSON.stringify`, spread, `getOwnPropertyDescriptor`, `in`, `delete` forward correctly; `util.inspect`-style printers show a Proxy (provide `gnoblin.inspect`).                                                                                                                                                                                                                                                                                                 |
| Not observed                               | In-place mutation of nested objects/arrays (`this.items.push(x)`), writes via raw targets (none exist), private fields. Spec §16 already states this limitation. Provide opt-in `tracked()`/`ObservableArray` types; do **not** deep-wrap plain values (would break `const a=[]; this.items=a; a.push(1)` identity).                                                                                                                                                           |
| TS                                         | Erasable-only stripping keeps native class fields (define semantics), so the trap sees them. TS `enum`/`parameter properties`/decorators are not erasable → rejected.                                                                                                                                                                                                                                                                                                          |
| Hot reload                                 | The proxy and its handler are gen-scoped JS objects; dropped with the runtime.                                                                                                                                                                                                                                                                                                                                                                                                 |

Alternatives considered:

| Option                                                                                                                                                                                                                                  | Verdict                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **(B) Boundary diff**: registry of observed objects; at each transaction boundary (end of event handler, `requestTransition` callback, after each job-pump turn) enumerate own enumerable data props and diff against the last snapshot | Zero identity/private-field/perf distortion, trivially correct for the transactional model (native reads state only at boundaries). Loses intra-handler ordering/attribution and eager validation errors pointing at the writing line. **Best fallback and test oracle** (run both in tests, assert same dirty sets). Cost O(fields) per live observed object per boundary [I].                                                                                              |
| (C) Exotic native class base (rquickjs `ClassKind::Exotic`)                                                                                                                                                                             | Rejected: ng consults exotic `set_property` only when no ordinary own property exists (`quickjs.c:10554+`), rquickjs has no `define_own_property` hook, class fields use define semantics (bypass), and rquickjs has no `new_target` access, so `class X extends NativeBase` prototype wiring needs a spike. It would also force all user fields into custom storage. Raw-FFI `JSClassExoticMethods` with all hooks is possible but is a mini object-model reimplementation. |
| (D) Lazy accessor installation via exotic prototype hook                                                                                                                                                                                | Rejected: first write only, descriptors become accessors, class fields bypass it.                                                                                                                                                                                                                                                                                                                                                                                            |
| (E) Decorators / `accessor` keyword                                                                                                                                                                                                     | Not erasable TS and not known to be supported by QuickJS [U]; violates "no decorators".                                                                                                                                                                                                                                                                                                                                                                                      |

**Decision**: (A) with `defineProperty`/`deleteProperty` traps, plus (B) at transaction boundaries for nested tracked containers. Gate (A) on a micro-benchmark (read/write ns, layout compute at 200 children); if reads dominate, ship (B) as primary and keep (A) off.

## 5. (b) Hot reload: generation = fresh Runtime + Context

Why fresh Runtime, not just fresh Context: QuickJS keeps the module cache per context and has no eviction API [V rquickjs Module API lists none]; a new Runtime also gives clean memory accounting, a clean `JS_SetMemoryLimit`, no shared atoms/shapes leakage, and isolates staging from the live generation. A Context "can share objects with other contexts of the same runtime" [V], which is the wrong default for isolation. Cost per generation ≈ Bellard's "<300 µs" runtime life cycle plus stock-library bytecode load [I]; measure.

Pipeline (all on the JS thread):

1. **Trigger**: file event (debounced), `reload` IPC command, SIGHUP.
2. **Build** generation N+1: runtime limits, interrupt handler, `set_loader(resolver, loader)`, context with intrinsic subset, host bridge in **staging mode** (every native-mutating call is recorded into a `Staged` transaction; timers, listeners, input binds are registered inertly).
3. **Stage**: `Module::import(ctx,"file:~/.config/gnoblin/init.{ts,js}")`, then pump `execute_pending_job` with a job-count + wall-clock cap (top-level await supported); init promise must settle or it is a failure. Errors: `Ctx::catch()` → exception message/stack; with position-preserving TS stripping, file:line:col is already correct.
4. **Validate**: object schema checks, import graph complete, ids unique, reconciliation preview against the persistent native graph (spec §18.1-3). Everything staged inside the child process; nothing reaches the compositor yet.
5. **Commit**: send one `Transaction{generation, ops}` to the compositor; it applies atomically at a frame boundary and replies `Applied(gen)` or `Rejected(reason)`. Only on `Applied`: make N+1 current, detach N's listeners/input binds by generation id on the Rust bridge, run `onCancel` for non-migratable grabs.
6. **Swap & drop**: pass explicit hot state (`gnoblin.hot.data`, JSON via `Ctx::json_stringify` / `rquickjs-serde`) from N to N+1 _before_ N is dropped (never module-level variables, spec §18). Drop order: all `Persistent`/`Class`/`Value` handles → `Context` → `Runtime` (struct field order). A leaked JS value at `JS_FreeRuntime` trips an engine assert unless assertions are disabled (`disable-assertions`; exact `NDEBUG` condition in `sys/build.rs` not read [U]); under process isolation an abort only restarts `gnoblin-js`, but treat as a bug.
7. **Failure**: drop N+1, keep N running, surface the report (module, line:col, object, field, reason). Keep the failed staging generation alive and read-only for N minutes for `inspect`/REPL post-mortem [I].

**Module cache invalidation.** (i) Runtime-level: nothing to invalidate; new Runtime = empty module table. (ii) Cross-generation _bytecode_ cache in Rust: key = `(canonical path, blake3(source bytes), BC_VERSION=29 [V], ng/rquickjs version, TS-strip crate version)`; value = `Module::write` bytes; hit → `unsafe Module::load`; **bytecode load is unsafe on untrusted input**, so keep the cache in a 0700 dir owned by the user and verify an HMAC/hash over the blob before loading. (iii) The Loader records `(path, hash)` for every file read, **including negative lookups** (`./x` candidates `.ts/.js/.mjs/index.*`) → that set is the watch set. Use content hashes, not mtimes: re-hash is cheap and handles `git checkout`/atomic saves. Canonicalize symlinks (stow/home-manager) in the Resolver and record both link and target.
Resolver: bare `gnoblin`, `gnoblin/<mod>`, `gnoblin/extensions/<id>` → builtin bundle; `./`/`../` → normalized under the config root only (reject `..` escapes and absolute paths); everything else → resolution error. `.ts/.mts` files pass through type stripping (below). Set `import.meta.url/dirname` in the Loader via `Module::meta()` [V API].

**File watching.** `notify` 8.2.2 stable (inotify backend; 9.0.0-rc.8 exists, avoid rc) + `notify-debouncer-full` 0.7.0, or raw `inotify` 0.11 for fewer deps. Watch **parent directories non-recursively** (editors replace inodes via rename), debounce ~100 ms, drop editor junk (`*.swp`, `*~`, `.#*`, `4913`), compare hashes against the generation's graph before reloading (no change → no reload), treat `IN_Q_OVERFLOW`/watcher errors as "possibly changed". Mind `fs.inotify.max_user_watches` (dir-level watches keep counts low). Re-arm watches after every successful generation from the new graph.

**TypeScript.** Strip, don't transpile: `swc_ts_fast_strip` (crates.io 60.0.1; Node-style type stripping which blanks types with whitespace so positions are preserved [U, from its design lineage, check `Mode::Strip`]) in the Loader for `.ts/.mts`; tsconfig `erasableSyntaxOnly: true` in the shipped template [TS 5.8 flag, U here]. This avoids source maps in stack traces, REPL and error reports. If Oxc/SWC _transform_ mode is needed later, add `sourcemap` 9.3.2 + `Error.prepareStackTrace` (ng has it [V diff.md]). Type checking stays editor/CI side.

## 6. (c) Budgets, and keeping the compositor alive when a script loops

Layers, cheapest first:

| Layer                  | Mechanism                                                                                                                                                                                                                                                                                                                                                | Catches                                                    | Misses                                                                                                                                                                                                                                   |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| L1 per-call CPU budget | Interrupt handler reads `Arc<Budget>{deadline_ns, kill}`; the host sets `deadline = now+budget` before every host→JS call and clears it after. Handler = `kill                                                                                                                                                                                           |                                                            | now>deadline`(set once with`set_interrupt_handler`; checked every 10 000 ticks at calls/back-edges and in regexp [V]). Returning `true`raises an **uncatchable** error:`try/catch/finally` all skipped [V], so scripts cannot swallow it | `while(true){}`, deep recursion loops, regex backtracking, `Promise` chains per job | one long native builtin that never polls (huge `String.prototype.repeat`/`JSON.parse`, BigInt ops [U]) |
| L1b job pump           | cap jobs + wall time per loop turn; `Promise.resolve().then(spin)` chains must yield to IPC/timers; overflow = handler strike                                                                                                                                                                                                                            | microtask storms                                           | –                                                                                                                                                                                                                                        |
| L2 memory              | `set_memory_limit` (libc allocator only [V]), `set_gc_threshold` (~¼ limit [I]), `set_max_stack_size` (default 256 KiB [V]); on OOM QuickJS throws a **catchable** InternalError, so L1 still bounds loops that catch it [I]. Bridge-level caps: max writes/objects per transaction, max string/array crossing the boundary (spec §16 "property limits") | runaway JS heap                                            | Rust-side/host allocations (needs cgroup)                                                                                                                                                                                                |
| L3 hard watchdog       | heartbeat updated each loop turn; if stale > T, watchdog sets `kill` then SIGKILLs `gnoblin-js`; supervisor restarts (exponential backoff, crash-loop → stock shell without `init`)                                                                                                                                                                      | everything, including non-polling builtins and engine bugs | –                                                                                                                                                                                                                                        |
| L4 OS                  | cgroup MemoryMax / RLIMIT_AS, Landlock, seccomp                                                                                                                                                                                                                                                                                                          | engine memory-safety bugs, escape attempts                 | –                                                                                                                                                                                                                                        |

Policy [I]: suggested defaults (configurable): handler 50 ms hard (8 ms soft warning), staging/`init` 5 s, REPL eval 2 s, job pump 4 ms per turn. After an **interrupt** the generation is suspect (finally blocks were skipped): mark the offending listener/binding failed; after N strikes in M seconds, tear down the generation and fall back to last-known-good native policy / stock shell (spec §18 failure rules). Interrupted staging ⇒ discard that generation. Compositor side: never wait on JS; coalesce input while JS is behind but keep press/release/cancel ordering (spec §17 rules); session lock and grabs stay native.

## 7. (d) What an LSP, inspector and REPL need

- **LSP**: nothing embedded. Ship generated `gnoblin.d.ts` (from the same Rust object schema that drives `native.newObservable`/class registration; one source of truth), `declare module "gnoblin"`, `"gnoblin/*"`, `"gnoblin/extensions/*"` (from extension manifests), global `gnoblin`, plus a template `tsconfig.json`/`jsconfig.json` (`erasableSyntaxOnly`, `allowImportingTsExtensions`, `noEmit`, `checkJs`). Editors use tsserver/typescript-language-server [U on specific server]. Optional `gnoblin check` runs `tsc --noEmit`. Runtime does not type-check.
- **REPL/inspector server**: line-delimited JSON on `$XDG_RUNTIME_DIR/gnoblin/js.sock` (0600, `SO_PEERCRED` uid check), enabled by default only for the owning user. Ops: `eval{gen?,expr,await?}`, `complete{prefix}` (JS-side own-property walk up the proto chain), `inspect{path|id}`, `gens`, `modules`, `handlers` (calls/avg/max/strikes), `timers`, `stats` (`Runtime::memory_usage` [V], `run_gc`), `reload`, `kill`. Never return live handles across the socket.
- **Observability hooks**: `set_host_promise_rejection_tracker` → inspector + strike [V]; `Error.captureStackTrace` available [V ng]; `console.*` → ring buffer + journald with generation id; per-handler timers recorded around `run()`; module graph from the Loader; object graph from the Rust registry (spec §18 inspector expressions).
- **Debugger**: QuickJS has no debug/inspector protocol; ng source shows no `debugger` opcode (`grep OP_debugger` empty) [V]. Do not promise breakpoints/stepping; offer logging, stack traces, REPL post-mortem on a retained failed generation, heap stats. V8's built-in DevTools inspector is the only engine here with a real debugger (escape hatch). Third-party QuickJS debugger forks exist [U], not evaluated.
- **TS in REPL**: strip before eval when the buffer is marked TS; errors stay position-accurate (whitespace stripping).

struct GenLoader { cache: Arc<BytecodeCache>, graph: Rc<Graph> }
impl Loader for GenLoader {
    fn load<'js>(&mut self, ctx: &Ctx<'js>, name: &str, _: Option<ImportAttributes<'js>>) -> Result<Module<'js>, Error> {
        if let Some(m) = builtin_bundle(ctx, name)? { return Ok(m); }          // embedded stock bytecode
        let (src, hash) = read_hash(name)?;                                    // also record negative lookups
        self.graph.0.borrow_mut().push((name.into(), hash));
        if let Some(bc) = self.cache.get(name, &hash) { return unsafe { Module::load(ctx.clone(), &bc) }; } // HMAC-checked
        let src = if name.ends_with(".ts") { ts_strip_keep_positions(&src)? } else { src };

        self.cache.put(name, &hash, m.write(Default::default())?);
        Ok(m)
    }

struct Generation { ctx: Context, rt: Runtime, id: u64, budget: Arc<Budget>, graph: Rc<Graph> } // ctx drops before rt
impl Generation {
    fn build(id: u64, cfg: &Cfg, cache: Arc<BytecodeCache>) -> Result<Self, Error> {
        let rt = Runtime::new()?;                                              // libc allocator so memory limit works
        rt.set_memory_limit(cfg.mem); rt.set_gc_threshold(cfg.mem / 4); rt.set_max_stack_size(512 << 10);
        let budget = Arc::new(Budget::default()); budget.deadline_ns.store(u64::MAX, Relaxed);
        let b = budget.clone();
        rt.set_interrupt_handler(Some(Box::new(move || b.kill.load(Relaxed) || now_ns() > b.deadline_ns.load(Relaxed))));
        let graph = Rc::new(Graph::default());
        rt.set_loader(GenResolver { root: cfg.root.clone() }, GenLoader { cache, graph: graph.clone() });

            .build(&rt)?;
        Ok(Generation { ctx, rt, id, budget, graph })
    }
    fn run<R>(&self, d: Duration, f: impl FnOnce(Ctx<'_>) -> R) -> R {          // L1 budget around every host->JS call
        self.budget.deadline_ns.store(now_ns() + d.as_nanos() as u64, Relaxed);
        let r = self.ctx.with(f);
        self.budget.deadline_ns.store(u64::MAX, Relaxed); r
    }
    fn stage(&self, entry: &str) -> Result<Staged, Report> {
        self.run(cfg.stage_budget, |ctx| { install_staging_bridge(&ctx)?;
            let p = Module::import(&ctx, entry)?; pump_jobs(&self.rt, &p, MAX_JOBS)?; take_staged(&ctx) })
            .map_err(|e| Report::from_exception(&self.ctx, e))
    }
}
fn reload(cur: &mut Generation, cfg: &Cfg, cache: Arc<BytecodeCache>, comp: &Compositor) {
    let next = Generation::build(cur.id + 1, cfg, cache).and_then(|g| g.stage(&cfg.entry).map(|s| (g, s)));
    match next.and_then(|(g, s)| validate(&s).and_then(|_| comp.commit(s)).map(|_| g)) { // atomic at a frame boundary
        Ok(g) => { let hot = cur.export_hot_state(); let old = std::mem::replace(cur, g); cur.import_hot_state(hot);
                   old.detach_listeners(); drop(old); rewatch(&cur.graph); }
        Err(rep) => report(rep), // keep `cur`; retain failed gen for post-mortem
    } }

## 9. Recommendation (one paragraph)

Embed **rquickjs 0.14.0 (quickjs-ng core)** in a **separate, supervised `gnoblin-js` process**, one `Runtime`+`Context` per generation (stage → validate → commit through the compositor → swap → drop), a custom Resolver/Loader with content-hashed bytecode cache and position-preserving TS stripping, L1 interrupt-handler deadlines plus watchdog/cgroup/Landlock backstops, observable user fields via a base-constructor Proxy trapping only `defineProperty`/`deleteProperty` (with boundary diffing as fallback/oracle), and a JSON socket REPL/inspector; generate `gnoblin.d.ts` for editors rather than embedding an LSP.

## 10. Open risks

1. **No head-to-head perf data** (Bellard 2026-06 vs ng 0.16.x) for gnoblin-shaped workloads; "42% faster" is Bellard vs his own previous release. Spike: layout compute at 50/200 children, startup time of stock library, per-generation cost.
2. **Proxy read/write overhead** and any QuickJS Proxy edge cases (receiver semantics for `Reflect.defineProperty` through the trap; private fields on Proxy objects; `new.target` pass-through) are inferred from the spec + engine source, not run. Spike with a test262-style probe before committing the observable design.
3. **rquickjs has no `new_target` in `Params`** and no exotic `define_own_property`: native-class subclassing and engine-level hooks need raw FFI or a `rquickjs` patch if option (A) is rejected. [V from source files read]
4. **Uncatchable interrupt skips `finally`** → torn invariants in script and in host state (e.g. half-registered listeners). Strike policy and "discard generation" behavior must be designed, not left to chance.
5. **Non-polling builtins** (huge string ops, BigInt, `JSON.parse`, big array sorts without JS comparator) can ignore the handler; only the watchdog + memory limit protect. Not tested.
6. **Memory limit is a no-op with `rust-alloc`/`allocator`**; do not enable them casually. Memory-limit exhaustion yields catchable errors [I].
7. **Leaked handles at `JS_FreeRuntime`** (Rust `Persistent`s, native-class cycles) can abort the process if assertions are on; the exact `NDEBUG`/`disable-assertions` wiring in `rquickjs-sys` was not fully read [U].
8. **Bytecode loading is `unsafe`** and version-bound (`BC_VERSION 29`, may change with every ng bump). Needs authenticated cache + version in key; corrupted cache must fall back to source.
9. **rquickjs README is stale** (says ES2020); real language level is whatever ng 0.16.x ships. Pin the ng commit in `Cargo.lock` and run an ES feature probe in CI; rquickjs bumps ng on its own schedule (0.13 → ng 0.16.2).
10. **`parallel` is experimental**: single-threaded JS ownership is a hard rule; all async host I/O must marshal through channels. `Runtime` methods take a mutex; calling them from the interrupt handler or from inside `Ctx::with` callbacks can deadlock [V+I].
11. **TS stripping crate behavior** (`swc_ts_fast_strip` modes, error reporting for non-erasable syntax, Node/Amaro lineage) is [U]; fallback is Oxc/SWC transform + source maps (`Error.prepareStackTrace` is available). MSRVs of Oxc (1.97) and notify rc/debouncer (1.91) exceed rquickjs's 1.87: pin toolchain accordingly.
12. **inotify edge cases**: symlinked config dirs, atomic-rename saves, queue overflow, watch limits; partial saves producing syntactically invalid intermediate files (debounce + failure keeps old generation; avoid reload storms).
13. **Spec conflict to resolve**: spec §3 says TypeScript is editor-side only; this report implements the owner's override (strip at load). Source positions rely on whitespace-preserving strip; any transform mode breaks that.
14. **No step debugger** on QuickJS; if the owner requires breakpoints, that is a V8 argument (cost: size, build, JIT in the shell process).
15. **Extension `.so` classes** (spec §17) run in an extension host; JS-visible classes must be bridged by ID/message, not `dlopen`ed into the JS process (`dyn-load` must stay off). Object-fidelity cost of the bridge (round-trips per property read) is unmeasured.
16. **Wasm/V8 alternatives were not benchmarked** and judged by architecture fit only.
