# Adwaita vector cursor source

Original artwork: [GNOME Project](https://www.gnome.org/).
Source: [adwaita-icon-theme 49.0](https://github.com/GNOME/adwaita-icon-theme/tree/49.0/src/cursors),
commit `084370e79b7f02cec50ab70c82da49f64b45f120`.

`adwaita.svg` is an unchanged copy of the upstream cursor sheet. SHA-256:
`3da7cbdaacb51ba90e6b7f903792f2ca58ca0ac3e01ba69c0cac248e397ba500`.
`cursors.json` contains the hotspots, frame counts and frame times from upstream
`cursorgen.py`, plus the installed Fedora 49.0 cursor aliases declared by
upstream `meson.build`.

The artwork is dual-licensed under LGPL v3 or CC BY-SA 3.0. The upstream licence
files are included. The generated theme attributes GNOME and retains these
licences. Gnoblin's conversion crops the original vector sheet and removes
unrelated shapes; it does not trace bitmap cursors or alter the design.
